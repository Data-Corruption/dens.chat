# Dens — Milestones

What each milestone built, and the plan for the one under way; ideas no milestone has taken up yet are in [loose-ideas.md](loose-ideas.md). The design they build toward is [design.md](design.md), with each deployment form's in [installed.md](installed.md), [flatpak.md](flatpak.md) and [android.md](android.md): a section named here, such as Global shortcuts, is one of theirs unless it's one of this file's.

A milestone's plan is written here first, and reviewed before anything is built. Once the milestone is done, what its plan still teaches, such as spike findings and measurements, moves into the design docs' sections, and the rest goes; Git keeps it.

Each milestone ends usable on its own and is tested on Linux and Windows, in Chromium and Firefox. As a rule, each step of a milestone is tested by the automated checks: the harnesses, the Android e2e in the emulator, and the browser checks in the container's Chromium and Firefox. The manual tests, on the phones and in browsers, run together once, at the milestone's end. A spike runs its own trials, and a test that can't wait for the end gets an exception. Platform-specific code stays behind the seams AGENTS.md's "OS seams live in two places" names, so the rest of a milestone is shared code.

## Repo cleanup

### Picks

1. **A fresh clone builds.** Options: one shared script that writes the placeholder files; or `ui` reads the manifest from the directory it embeds, and where the build wrote none, serves a placeholder page of its own. Pick the second: nothing has to run first, and the fixture binaries the e2e harnesses build, which start real services, get the page tests get. Tried in a scratch clone: build, vet and the tests of `ui`, `service` and the routers pass with no placeholder file. A binary a script builds carries a build value that requires the real page, and refuses to start without it; only the fixtures' script leaves it out, and a bare `go build` or `go test` has none.
2. **Lint.** `-lint` runs gofmt over every Go file, vet for Linux, Windows and Android, shellcheck over every tracked script but the sourced libraries it names, and the docs' link check (pick 9). CI runs it first, in a checkout nothing has written to, which makes it the test of pick 1.
3. **One Go.** Options: leave it; say it in AGENTS.md; or the scripts, the generators among them, export `GOTOOLCHAIN` as go.mod's version and use that toolchain's gofmt. Pick the last: what passes here is what CI builds, and CI compares what the generators format byte for byte. Checked: gofmt and the three vets pass on 1.26.7.
4. **Searches.** Options: `.ignore` alone; or `.ignore`, with `.gitattributes` marking the generated files `linguist-generated` and the media module `-diff`, and a line in AGENTS.md. Pick the second: `.ignore` doesn't reach every tool's search, and the attribute also keeps 24 MB out of a diff. A bare `grep -r` still walks the module where a tool reads `.gitignore` alone, so the line in AGENTS.md says to search with `git grep -I` or `rg`.
5. **Editor files.** `flake.nix` goes, with `build.sh`'s pointer to it: nothing has kept it current. `.vscode/settings.json` goes too: no editor's settings are the repository's to keep.
6. **AGENTS.md.** One line per path with no tags; each package's detail in its doc comment, written as what the package owns now; the page's row a pointer to the comments its files open with. The rules stay, with the four for generated files told as one shape, Documentation folded into Writing, and the stale lines fixed. The commands carry their durations, and what running them costs: `build.sh` empties `out/`, one heavy suite at a time. About 20 KB.

### Steps

Each is a branch from main and a pull request, in this order.

1. **Tooling** (`cleanup-tooling`): picks 1 to 5; the usage printers, which print their header whatever its length, the stale guide link, `flatpak-vm.sh`'s default and its example; the script headers and workflow comments that no longer match what they head; the commands' durations in AGENTS.md. Checked by `-lint` in a fresh clone before anything else runs, the race suite, `-js`, `-e2e` and `-den-e2e`, whose fixture binaries serve the placeholder page, `-windows`, and every CI job, since it changes the workflow.
2. **AGENTS.md and package docs** (`cleanup-agents`): pick 6, and CONTRIBUTING.md's errors, its command list a pointer. Checked by `-lint`, the race suite, and `go doc` for each package rewritten.
3. **The docs** (`cleanup-docs`): picks 7 to 11; the 53 failures the audit found in design.md and protocol.md; the form docs' contradictions; the release table; the checklist sorted by area, its stale item fixed. Checked by the move's script, `-lint`'s links, and `-docs`.
4. **The notes** (`cleanup-notes`): pick 12. As checks: a test that fails on a route registered twice, which the router otherwise takes silently; a check's leftover browsers and the emulator's stale lock cleared before a run; `scripts/dev/stage.sh`, which stages a manual test's builds as a prerelease of the coming version. Then workflow.md, testing.md, the comments and the doc lines; and, outside the repository, the notes archived and cut to what is personal. Checked by `-lint`, the race suite, and each harness whose script changed.
5. **Tags out of comments** (`cleanup-tags`): the parenthetical tags by script in one commit, the tags in prose by hand in another. None changes in a released migration's SQL, the cache's schema or test data; the emoji list's one tag goes from its generator, which writes the list again; the media driver's three stay, since its module would have to be built again; and the PowerShell harnesses keep their CRLF. The installers hold none, so nothing published changes. Checked by the page's bundle built before and after, byte for byte the same; for the scripted commit, a script that finds only comment lines changed and no line count moved; and the suites.
